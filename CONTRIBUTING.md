# Contributing

Thanks for your interest in improving the Dallass Mini App.

## How to help

- **Bug reports:** open an issue with the device, Telegram version, and steps to reproduce.
- **Pull requests:** keep the single-file, zero-dependency design — no build step, no frameworks. Test the change inside Telegram's WebApp (or a mobile browser) before submitting.
- **Translations / RTL fixes:** Persian is the primary language; fixes for RTL layout and Persian digit rendering are especially welcome.

## Ground rules

- Do not commit real shop credentials, bot tokens, or supplier pricing sources.
- Keep the catalog structure backward compatible where possible, and note breaking changes in the PR description.
